# Skill-first workflow

Before starting any task:

1. Check whether an existing (already installed) skill can help with the requested task.
2. Use the `find-skills` skill to search the skills.sh ecosystem when a relevant skill may exist
   (`npx skills find <query>`).
3. Evaluate the best candidates on quality, popularity (installs), author reputation and relevance.
4. Present the best option with its installation command, e.g.
   `npx skills add <owner/repo> --skill <name> -g -a claude-code`.
5. Never install third-party skills without explicit approval from the user.
6. If no suitable skill exists, complete the task with your own capabilities or propose creating a custom skill.

Do not start complex work before checking for relevant skills.
