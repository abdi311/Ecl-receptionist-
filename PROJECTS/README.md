# Progetti

Una cartella per progetto, sempre con gli stessi quattro file. Per un nuovo progetto copia
`_modello/` in `PROJECTS/<nome-progetto>/` e aggiungilo alla tabella in `MEMORY.md`.

| File | Contenuto |
|---|---|
| `STATO.md` | Fotografia attuale: a che punto è, dove sta il codice, come provarlo. Si riscrive. |
| `CRONOLOGIA.md` | Cosa è stato fatto e quando. Si aggiunge, non si cancella. Più recente in cima. |
| `DECISIONI.md` | Decisioni del progetto con motivo. Si aggiunge; le superate restano marcate. |
| `TODO.md` | Attività da completare, in corso e completate. |
