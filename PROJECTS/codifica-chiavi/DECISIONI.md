# Codifica chiavi – Decisioni

- **2026-11-19** – Metodo predefinito: **clone del transponder** (più veloce, nessun collegamento OBD).
  Si passa all'OBD solo se il chip non è clonabile o è una chiave keyless. Guida in [GUIDA-CLONE.md](GUIDA-CLONE.md).
- **2026-11-19** – I manuali non si copiano nel repository (sono protetti da copyright): si salvano
  i link e un riassunto pratico in italiano in `GUIDA-STRUMENTI.md`.
- **2026-11-19** – Strumento di partenza per aggiungere una chiave via OBD: Autel IM608 con
  *Hot Function → Add Key (guided)*; OBDSTAR G3 come alternativa quando Autel non supporta l'auto.
- **2026-11-19** – Niente dati sensibili nelle schede: niente VIN completi, PIN, codici o dati clienti.
